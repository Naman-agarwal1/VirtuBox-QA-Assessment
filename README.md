# VirtuBox QA Assessment – Task Management Application

This repository contains my QA assessment work for a Task Management Application.

## What is included

- Manual test scenarios and test cases
- Positive, negative and edge cases
- Potential bug/risk identification
- A small working Task Management web application for practical testing
- Basic validation and user/task CRUD flows

## Application features

- User registration
- Login/logout
- Create task
- View task list
- Edit task
- Delete task
- Basic input validation
- User-specific task data

## How to run the practical application

No server is required.

1. Open `app/index.html` in a browser.
2. Register a new user.
3. Login with the registered account.
4. Create, edit and delete tasks.
5. Refresh the page and verify persistence.

Data is stored in browser localStorage for this demo.

## QA documents

- `qa/Test_Cases.md` – test cases for registration, login, CRUD and validation
- `qa/Bug_Risks.md` – potential bugs/risk areas identified before execution
- `qa/Test_Strategy.md` – short risk-based testing approach

> Note: Items in Bug_Risks.md are potential risks unless explicitly marked as reproduced. They are not presented as confirmed defects without execution evidence.
